# YuSkill 信号速查

> 一张表看懂局面。信号是唯一的行动依据，不拍脑袋。

---

## 一、红绿灯模型

### 🟢 绿灯（积极信号）

| 信号 | 说明 |
|---|---|
| 主动开启话题 | 不用你找话，她自己来找你 |
| 回复快且长 | 有表达欲，不是应付 |
| 用表情包、语气词 | 情绪投入，放松状态 |
| 问关于你的问题 | 对你这个人有兴趣，不只聊事 |
| 配合你的话题升级 | 你带一点暧昧，她接得住 |
| 主动给时间 | "我周六有空"——直接给窗口 |

**看到绿灯 → 可以加速**：植入轻度暧昧话题、发出具体邀约。但绿灯不代表可以掉以轻心，仍要一次只做一个动作。

### 🟡 黄灯（中性信号）

| 信号 | 说明 |
|---|---|
| 回复但不主动 | 有礼貌，没热情 |
| 回复短 | "嗯""哈哈""表情包"三件套 |
| 不冷不热 | 不拒绝也不推进 |
| 偶尔主动，偶尔消失 | 信号不稳定 |

**看到黄灯 → 稳框架**：不追问、不表白、不加码。用有意思的内容激活，激活不了就收线等下次。**黄灯期最忌讳**：连续追问"你怎么了"、发小作文表白、用更强的话术硬救。

### 🔴 红灯（消极信号）

| 信号 | 说明 |
|---|---|
| 回复很慢或不回 | 连续多轮明显变慢或直接不回（看趋势不看单轮） |
| 敷衍 | 连续"嗯""哦"，无实质内容 |
| 明确拒绝 | "别联系了""我有对象了" |
| 反复取消 | 多次取消且不给替代方案（看模式不看单次） |
| 躲避 | 看到你绕道、已读不回装没看见 |

**看到红灯 → 停止主动**：给空间，不追问"我是不是说错什么了"（这暴露极强需求感）。连续三次红灯 = 体面退出，见话术库第六节。

## 二、投入度指标（三档）

| 指标 | 高 | 中 | 低 |
|---|---|---|---|
| 主动开启话题 | 经常 | 偶尔 | 从不 |
| 回复长度 | 长句+细节 | 短句应付 | 表情包/单字 |
| 提问 | 问你的生活、想法 | 只回不问 | 无 |
| 邀约接受度 | 给具体时间 | "下次吧"无下文 | 直接拒绝/消失 |
| 分享欲 | 主动分享日常 | 问才说 | 不说 |
| 线下投入 | 愿意花时间见面 | 推三阻四 | 不见 |

**用法**：连续一周，4 项以上"低" = 红灯；3 项以上"高" = 绿灯；其余为黄灯。

## 三、分阶段看什么

### 前期（刚认识，信号不明）

**看**：她回不回、回多快、回多长
**不看**：她喜不喜欢你（现在看不出来，看了也白看）
**做**：稳框架，做好自己该做的，不追问、不表白

### 转折期（有好感信号或暧昧氛围）

**看**：她是否主动、是否配合话题升级、是否给时间窗口
**不看**：单次回复的速度（看趋势不看单次）
**做**：真诚表达，一次一个动作（表白/邀约/推进三选一，不堆叠）

### 稳定期（关系已确定）

**看**：投入是否对等、冲突如何处理、有没有长期规划
**不看**：每条消息的措辞（稳定期抠字眼是内耗）
**做**：经营投入、处理冲突、规划未来，见 `诊断/关系.md`

## 四、一句话决策表

| 你看到 | 你做 |
|---|---|
| 她主动找你聊天 | 正常接，话题可以深一点 |
| 她回复快且长 | 可以推进一小步（邀约/暧昧二选一） |
| 她只回"哈哈" | 收线，等下次 |
| 她连续几轮不回 | 不追问，忙自己的，过几天可再开一次话题 |
| 她明确拒绝 | 停止，体面退出 |
| 她反复取消约会 | 把主动权交还："你确定时间再告诉我" |
| 她问你"你是不是喜欢我" | 绿灯信号，真诚回答，不要绕 |
| 你忍不住想发小作文 | 先存草稿，睡一觉再看；90% 的小作文都不该发 |
| 你想问"我哪里做错了" | 不问。复盘自己看，不问对方要答案 |
