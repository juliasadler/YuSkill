# 约会诊断

## 适用场景

用户问「这次约会哪里出问题了」「她为什么后来不理我了」，需要对一次约会从头到尾诊断时，路由到本模块。

## 诊断流程

先收信息。缺一项就追问，不收齐不下结论。

问清：怎么认识的、约过几次、地点和转场、做了什么、她全程的反应、肢体到了哪一步、最后结果。只有结果没有过程，诊断一定是错的。

### 第一步：吸引诊断——看你在传递什么

公式：价值感 = 实际价值 + 价值传递。传递为零，实际价值再高也没用。

判断标准：
- 有没有表达自己的想法和生活，还是全程附和她的话题
- 讲没讲过完整故事，还是只在晒经历、晒消费
- 见面态度是轻松平等，还是把简单见面搞成严肃仪式

结论：吸引力高 / 中 / 低。指出具体哪个环节在传递价值、哪个在掉价值。

### 第二步：框架诊断——看谁在带节奏

框架不是谁压谁，是谁在带节奏、谁在跟随。

判断标准：
- 地点、转场、升级动作是谁决定的
- 有没有解释自己的行为（解释=低位）
- 是不是每一步都在等对方信号才敢动（等=低位）
- 怕不怕她不高兴（怕=低位）

结论：高位 / 中位 / 低位。给出证据时刻。

### 第三步：节奏诊断——看亲密有没有跑在关系前面

这是最容易翻车的地方。亲密推进超过了两人真实的关系定位，就会出事。

判断标准：
- 肢体升级到了哪一步，关系定位到哪一步
- 亲密动作之后，有没有相应的关系框架跟上
- 她被推开过吗，推开后你停了吗
- 用过酒吗（灌酒=强迫，不是技术）
- 用过封闭空间吗（封闭空间施压=操控，不是吸引）

结论：节奏匹配 / 跑太快 / 跑太慢。跑太快必复盘，跑太慢看互惠。

### 第四步：状态诊断——看你是不是真稳得住

真稳：做也行、不做也行，不影响正常交流。不稳：表面装淡定，内心步步算计。

判断标准：
- 她冷淡时你慌不慌，她热情时你冲不冲
- 是不是带着「这次一定要成」来的（带着=需求爆表）
- 全程有没有一刻是真的放松

结论：稳 / 假稳 / 崩。假稳一定会被感知到，装不出来。

### 第五步：转场诊断——看升级路上有没有断点

好的约会：简单、便宜、离家近。邀约简单，消费不高，方便自然转场。

判断标准：
- 邀约有没有压力（订座、长规划=压力）
- 是不是在情绪还好的时候转场，还是拖到情绪掉光
- 转场理由是不是自然（不自然=暴露急切）

结论：合理 / 有断点 / 没转场。指出断在哪。

## 核心方法

六维合一，五句话。

1. **传递价值，不展示价值。** 讲故事、表态度、有自己的生活。晒钱晒物是掉价值信号。
2. **带节奏，不压节奏。** 决定地点和流程，但留拒绝空间。邀约格式：具体活动+具体时间+可拒绝。「周末一起喝咖啡？」比「哪天有空」强。
3. **亲密跟着关系走，不超前。** 每次升级都观察对方反应。被拒绝=停下来，不解释不道歉，继续正常走完约会。推开后硬推只有一种结果：失联。
4. **稳态来自不缺席自己的人生。** 有自己的事、不秒回、不粘人。需求感藏不住，真稳是内心的事。
5. **转场自然，小步走。** 情绪好时转场，转场理由具体具体真实。转场即升级：对方同意转场，就是在同意升级。

## 分阶段策略

**前期：信号不明。稳框架，不对冲。**

- 不升级亲密，只收集信息：她守时吗、她尊重人吗、她愿不愿意投入时间
- 邀约保持小而具体：一次约会验证一件事，不规划未来
- 她长期只回你发起、反复取消不重约：停，不是对冲，是及时止损
- 这个阶段的行动只有两个字：观察

**后期：她有明确好感，暧昧氛围已经起来。真诚表达。**

- 可以表达兴趣，可以推进关系定义
- 明确问一句，不猜：「我想吻你，可以吗」
- 关系定义不是逼婚：说清楚你们现在是什么，排他还是不排他
- 明确表达只发生在明确信号之后，不提前预支

**切换依据：只有信号。**

- 信号=她的持续行为模式：她主动找话题、主动安排、记得你说过的话、愿意在现实中见你
- 单一热情时刻不是信号，持续模式才是
- 看趋势不看单点。她今天很嗨明天消失，不算有好感。

**你现在要做的第一件事是：** 打开聊天记录，从头看一遍最近三次互动，标出每次的红绿灯颜色。如果两次以上是黄灯，先别约——回去把聊天模块的诊断跑一遍，把灯变绿再说。

## 常见误区

1. **花大钱买好感。** 消费越高需求感越高。花 800 没讲故事没表态度，等于零传递。消费不决定吸引。
2. **把拒绝当信号解读。** 「欲擒故纵」是自我安慰。反复取消、长期含糊、只在深夜联系：停。
3. **复盘代替实战。** 同一次失败约会诊断三遍，不去约下一次。复盘是手段，不是目的。
4. **把「约出来」当胜利。** 邀约成功不等于得手。见面后的传递、节奏、状态才是胜负手。
5. **追问最后一步哪里错。** 99% 的翻车败在框架和需求感，不是最后一分钟。那一步错了，是前面三小时的账。

## 伦理检查

这条线永远比技术高。

- **不同意就是不行。** 清楚、持续、自由、可撤回。沉默、僵住、过去同意、进入房间、接受礼物，都不等于同意。
- **不劝酒。** 用酒精降低对方判断力推进亲密，是强迫不是技术。见面别带「一定让她喝」的念头。
- **不利用封闭空间施压。** 去谁家、去酒店，都必须有她明确同意。转场理由可以自然，但不能有欺骗成分。
- **不把「约出来」当成「得手」。** 邀约成功是开始，不是完成。目标不是「拿下」，是更快发现双向匹配、减少互相伤害。
- **拒绝必须安全。** 她说停，你停。不怒、不羞辱、不纠缠、不「磨到同意」。
- **边界和控制的区别。** 你管自己叫边界，你管她叫控制。「你不许有异性朋友」是控制，不是边界。
- **隐私红线。** 不拍、不存、不传播私密影像，默认就是这个。未成年、醉酒、意识不清：直接停，不讨论技术。
