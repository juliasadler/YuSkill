# 认知与吸引力诊断

## 适用场景

用户把"她不喜欢我/我吸引力不够/追了很久没结果"归因于运气、颜值、钱或"做得还不够"时，路由到本模块——卡点在认知层，不在技术层。

## 诊断流程

四步走，每步先给结论、等用户回应后再走下一步。

**第一步：定位归因方式**

让用户用一句话说清"为什么她不喜欢我"。
- 归因于单一变量（颜值/身高/钱/缘分）→ 认知懒惰。
- 归因于"我对她不够好"→ 讨好型叙事。
- 归因于"她太物质/势利"→ 敌意化叙事，方向走偏。
- 能拆出自己可改变的行为项→ 认知基本在线，转其他模块。

判断标准：他的解释里有没有自己能动手的部分。没有，就卡在认知。

**第二步：测框架位置**

看三件事，全部可验证。
1. 联系节奏：谁主动得多？谁秒回得多？
2. 让步方向：有分歧时，谁先改口、谁先道歉？
3. 怕失去信号：她一冷淡，他是加倍投入还是保持节奏？

结论只有三种：低位（围着对方转）、中位（时好时坏）、高位（有自己的节奏和标准）。核心指标就是"怕失去"。怕失去的人没框架。

**第三步：测稀缺程度**

看两件事。
1. 注意力集中度：他的注意力压在几个人身上？只压一个人，就是稀缺。
2. 对拒绝的反应：一次没回应就焦虑、自我怀疑 → 稀缺心态实锤。

判断标准：稀缺心态是需求感的源头。最不需要对方的人，谈判位置最高。这不是装出来的，是选项多少决定的。

**第四步：测吸引/舒适结构**

问他：你们现在是"很熟但没火花"，还是"有火花但还不熟"？
- 高舒适低吸引（朋友区）：再怎么加舒适都上不去，吸引力不会被舒适替换。
- 高吸引低舒适（刚认识有感觉）：舒适可以后补，空间还大。
- 双低：还没开始，谈不上诊断。

判断标准：吸引力可以转化为舒适感，舒适感转不回吸引力。开局结构决定了天花板。

## 核心方法

融合后的实战打法，三条。

**一条：先拆认知，再谈技术。**

技术教不会一个认知卡死的人。顺序是：归因方式 → 框架位置 → 稀缺程度 → 开局结构。四个测完，结论自然出来。每个结论都要有他自己说过的原话做证据，不许空判。

**二条：价值感 = 实际价值 + 价值传递。**

条件不差但没结果的人，问题几乎都在后半句——价值传不出去。聊天像面试、朋友圈全是工作、约会紧张到说不出话，都是传递问题，不是条件问题。修传递比攒条件见效快。

**三条：用概率思维替代单点执念。**

把注意力从"这一个她"移到"足够样本下的正期望"。接受单次被拒绝，像接受一次正常损耗。不追求每次都成，追求长期胜率。这是稀缺心态唯一的解药——不是心态课，是把选择池做大。

## 分阶段策略

**信号不明阶段（她态度模糊、忽冷忽热）：稳框架，不对冲。**

- 保持自己的节奏，不追问、不加码、不解释。
- 不做任何"证明自己"的动作。证明=低位。
- 唯一动作：把省下来的精力投到自己的选择池和价值传递上。
- 切换依据：她有没有持续、主动、可验证的投入信号。没有，就一直稳住。

**有明确好感/暧昧阶段（她主动找你、愿意单独见面、身体语言开放）：真诚表达，推进关系。**

- 信号够了就别再端着。继续"稳框架"会变成冷暴力，亲手推开人。
- 表达要具体、真诚：欣赏她什么、想跟她走到哪一步，说清楚。
- 推进按她的回应节奏来：她进一步，你进一步；她停，你也停。
- 记住：信号是唯一的切换依据。感觉不算，猜测不算，只有可验证的行为算。

**两条红线贯穿全程：** 信号不明时表达=自杀式冲锋；信号明确了还端着=把到手的机会晾凉。

## 常见误区

1. **把"对她好"当策略。** 真诚的喜欢，妥协不出来。你以为在加分，她只感受到压力。好要放在信号明确之后，不是之前。
2. **从朋友做起。** 高舒适低吸引的开局，吸引力天花板是锁死的。想追就别先当朋友，当了朋友就别想追。
3. **单变量归因。** "我就是不够帅/没钱"。这是认知懒惰——把复杂问题压缩成一个改不了的变量，等于给自己发了免行动许可证。
4. **用学习代替行动。** "理论都懂就是不敢"。诊断做到这一步就停，路由到行动模块。再学更多理论只是拖延。
5. **把客观规律读成敌意。** "她慕强=她势利=女人都坏"。规律是中性的，读出仇恨是你自己的滤镜。带敌意进场，谈什么都崩。

## 伦理检查

本模块的禁区，碰一条就停。

- **可以分析权力动态，不可以用操控手段。** 看懂谁在高位是诊断；用冷暴力、忽冷忽热、故意制造焦虑去拿高位，是操控。不干。
- **互惠原则：** 任何策略不能建立在单方面榨取对方情绪价值上。她投入，你也要投入对等的东西。
- **可退出原则：** 对方任何时候说停，你停。不追问、不纠缠、不"再给一次机会"。她的"不"不需要理由。
- **边界原则：** 不利用对方的脆弱时刻（刚分手、情绪崩溃、喝醉）推进关系。那不是本事，是趁虚而入。
- **不物化：** 不把人当"目标""猎物""资源池里的一个"。诊断时可以谈结构，行动时对方是人。
