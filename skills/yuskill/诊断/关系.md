# 关系诊断

## 适用场景

当你搞不清"我和她到底算什么关系、该继续投入还是该收手"时，路由到本模块。

## 诊断流程

**第 1 步：定阶段。**
先判断关系处在哪个阶段。判断标准：是否有明确的关系承诺、最近互动频率、最近是否发生断裂事件。
- 暧昧期：未确立关系，互动正常
- 稳定期：已确立关系，互动正常
- 危机期：吵架、冷战、失联、出现第三者
- 已结束：分手、拉黑、明确断联

阶段定错，后面全错。阶段错了就回这一步。

**第 2 步：看位置动态。**
判断关系里谁主导节奏、谁迎合。只看行为，不看感觉：
- 谁主动联系多、谁敷衍回复？
- 谁决定见面频率和地点？
- 谁在不断调整自己、迎合对方反应？
- 谁害怕失去对方，怕到不敢提需求？

结论三档：主导位 / 平衡位 / 被动位。
位置动态只用来看懂局面，不许用来压制对方。

**第 3 步：查投入账。**
回看最近几次有代表性的互动，只记事件不记情绪：
- 发起：谁提出见面、通话、推进关系？对方不能来时给过替代方案吗？
- 兑现：重要承诺做到了吗？做不到时提前说明并补救了吗？
- 回应：你表达需求后，对方是理解关心，还是惩罚嘲讽？
- 修复：误会冲突后，有人承担影响并落实改变吗？
- 边界：你能说"不"吗？还保留自己的朋友和生活吗？

每条分成"已发生 / 我的解释 / 还不知道"。不要把礼貌、点赞、偶尔热情升级为承诺证据。
结论四档：
- 互惠但节奏不同：继续推进，协商节奏
- 证据不足：关系早期或样本太少，做一次能产生新信息的动作
- 持续失衡：长期只有你主动、对方接受好处却回避回应、反复失约不修复→停止加码
- 明确拒绝或危险：已拒绝、拉黑、威胁跟踪暴力→停止推进，危险走安全路径

**第 4 步：定类别。**
- 暧昧对象：未确立，互有好感
- 正式伴侣：已确立关系
- 友谊区：你被当情绪垃圾桶、男闺蜜，择偶范围之外
- 备胎：需要时召唤，不需要时晾着
- 已分手：关系已断

类别决定管理重点：友谊区和备胎不值得加码，只适合止损。

**第 5 步：给结论和第一行动。**
一段话说出本质问题。列出行动，按优先级排序。最后必须是："你现在要做的第一件事是……"

## 核心方法

**位置动态判断法。**
看懂谁主导、谁迎合，但不许用这个差去操控对方。你的好是"愿意给"，不是"必须给"。

**事实账。**
用事件不用感觉记账：发起、兑现、回应、修复、边界。感觉会骗人，账不会。

**投入校准阶梯。**
- 证据不足时先推进或澄清一次，例如："我很享受和你相处，也发现最近大多是我在发起。你还想继续了解彼此吗？想的话我们一起定个都舒服的节奏，不想也可以直接告诉我。"
- 澄清不是审讯：不堆证据，不逼即时承诺。对方已明确拒绝，不再"最后问一次"。
- 观察窗口绑到具体事件（下一次约见是否兑现、对方忙完是否主动联系），不天天重新解读一个表情。
- 没有改善就降级投入：停止单方面策划和救场，不再提供超出关系阶段的金钱、情绪劳动、随叫随到。降级的目的是恢复资源配置，不是让对方恐慌。
- 自检一句："如果对方没有追来，我是否仍觉得这一步对我有利？"如果答案是否，你是在用退场包装操控，停手。

**冲突分类与修复。**
冲突先分类：
- 信息误解→澄清事实
- 可解决的问题（时间、预算、任务）→制定方案
- 持续差异（整洁、社交、性需求）→管理，不追求消灭
- 核心不兼容（婚育、忠诚、城市、重大价值）→需要选择，不折中
- 权力与安全问题（控制、胁迫、暴力）→不适合双人沟通，走安全路径

修复五步：
1. 约时间定目标。避开对方赶时间、醉酒、疲惫、失控的时刻。
2. 软启动：具体事实→感受和影响→需要→请求。不说"你永远不尊重我"。
3. 高质量倾听：复述、确认、探问。确认感受不等于承认全部事实，也不等于放弃边界。
4. 共同定义问题：把"你对我错"改写成双方共同面对的张力。
5. 生成方案试行：先各提两个，不立刻批评；选成本可控的试行；明确谁、何时、做什么、何时复盘。

情绪淹没时可以健康暂停，四要素缺一不可：
1. 明说不是惩罚或消失
2. 给大致返回时间
3. 暂停期间做降唤醒活动，不写控诉长文
4. 按约返回，需要延长再通知

无限期断联、用沉默逼对方屈服，是冷暴力，不是暂停。

有效道歉至少包括：清楚说出自己的行为；承认造成的影响，不加"但是你也"；表达遗憾；问如何修补，不强求立刻原谅；给出具体改变并长期落实。

**退出决策。**
停止条件必须来自行为：再次无解释失约；一次清楚澄清后仍长期回避；再次越过已说明的边界；关系已让你持续失眠、欠债、失去正常生活且对方不愿协商。
达到停止条件就退出，不留"等一下"。

## 分阶段策略

**暧昧期：信号是唯一切换依据。**
- 信号不明时稳框架不对冲：先做事实账，证据不足就做一次能产生新信息的动作（具体邀约、澄清式提问如"你觉得我们现在算什么关系"），不加码。注意：这里的"表达"是澄清关系状态，不是表白好感——信号不明时表白=自杀式冲锋。
- 对方有明确好感、暧昧氛围成立时：真诚表达意图一次，不绕弯子，不纠缠。
- 信号切换：对方回避或持续失衡→回到降级投入；对方明确拒绝→退出。
- 你现在要做的第一件事是：停掉单方面策划，发起一次真实澄清。

**稳定期：管框架，造张力。**
- 框架最容易在稳定期滑落：定期自检——你是否又开始秒回、迎合、怕失去？
- 持续的情感张力是稳定期的必需品。关系稳定不等于互动平淡，只聊日常家务会杀死吸引力。（注：张力指真实互动中的吸引力，来自新鲜感和深度交流，不靠忽冷忽热、推拉、奖惩制造——那些是操控，不是张力。）
- 冲突走修复五步；核心不兼容不折中，要选择。
- 你现在要做的第一件事是：把注意力放回自己身上，恢复你的节奏和标准。

**危机期：先止血，再谈修复。**
- 吵架→走冲突修复流程，不隔夜翻旧账。
- 冷战→区分健康暂停和冷暴力：有返回时间、有明说的是暂停；没有的就是冷暴力，你不能用，对方用你要指出。
- 背叛→三阶段：稳定（停止进一步欺骗、处理安全）、理解（分清解释和开脱）、重建或结束（修复要持续诚实、可观察的改变）。
- 无法断联的关系（同事同学）→退出私人推进后转必要、简短、可留痕的事务沟通。
- 你现在要做的第一件事是：判断这是能修复的问题，还是核心不兼容。

**终点：退出也要体面。**
- 体面分手六步：相对私密但安全的场合；用明确结论，不给谈判假象（"我决定结束这段关系"）；简要说明主要原因，不人格羞辱、不列罪状；允许情绪，但不因对方哭闹撤回边界；讨论物品、财务、后续联系；不说"以后也许"，除非真有条件和意愿。
- 不发送讽刺总结、账单式控诉，不假装已有新欢，不说"你会后悔"。它们只会延长纠缠。
- 担心暴力、堵门、跟踪、自伤威胁→公共场所、远程或有第三方支持下结束，安全计划优先于"当面才有诚意"。

## 常见误区

1. **拿感觉当证据。** "我觉得她不爱我了"没有过程就没有诊断。要么从头讲过程，要么你得到的结论是错的。
2. **用"对她更好"挽回。** 低位加码等于更快掉位。挽回的核心不是对她更好，是立刻停止无效加码。
3. **把冷战当筹码。** 冷暴力是禁区，不是工具。暂停和冷暴力的区别只有一条：有没有返回时间、有没有明说。
4. **信号不明时对冲。** 证据不足就押上全部，是最亏的赌法。信号不明先稳，有明确信号才行动。
5. **混淆宽恕和继续。** 可以放下怨恨但不复合。复合的门槛：分手原因被准确命名、改变有行为证据、新规则已谈好。

## 伦理检查

**三条禁区，碰了就越线：**
- 禁冷暴力：无限期断联、拒绝回应、用沉默逼对方屈服。健康暂停必须给返回时间、必须按约返回。
- 禁奖惩操控：用投入和撤回来当手段控制对方、故意让对方恐慌。"如果对方没有追来我是否仍觉得有利"是自检红线。
- 禁煤气灯：篡改事实、让对方怀疑自己的感知。看懂位置动态，不等于可以扭曲对方的现实感。

**权力只看不用。** 能判断谁主导、谁迎合，但不许用这个差去压制、羞辱、逼迫对方。诊断是看清局面，不是拿到操控说明书。

**诚实面对关系状态。** 不用模糊话术糊弄承诺需求，不在暧昧里既要亲密又逃避责任。关系是什么状态，就用什么状态的规则。

**涉及控制、胁迫、暴力、自伤要挟：** 普通沟通训练不适用。安全计划优先，必要时寻求专业帮助和法律支持。

**退出必须体面。** 明确、私密、不羞辱、不曝光隐私、不报复。结束一段关系不需要证明对方是坏人。
