# 聊天诊断

## 适用场景

一段聊天看不明白了——不知道对方有没有兴趣、自己是不是聊错了、该不该继续——进来诊断。

## 诊断流程

**第 1 步：先把材料摆齐。**

只看聊天记录的可见原文，加上认识渠道、认识多久、当前关系（刚加 / 暧昧 / 邀约中 / 已约会）。材料不齐不诊断。单拿一句话问"这句怎么回"，结论一定是错的。

**第 2 步：锁说话人，不脑补。**

先确认记录里哪边是自己、哪边是对方。后续所有判断只基于原文能看到的事实：回复速度、长度、谁在主动开话题、原话说了什么。不猜"她其实是想……"，原文没有的，一律按未知处理。

**第 3 步：看框架，谁在主导。**

证据只认四件事：谁在主动开话题、谁在解释自证、谁在追问、表达好感时是高位还是低位。高位 = 有标准、不迎合；低位 = 讨好、怕失去、急于自证。

**第 4 步：看话题结构。**

逐句标：聊对方兴趣的、日常琐事的、展示自己的。日常琐事连轴转却没人接情绪、话题越聊越干，说明聊进了死胡同。

**第 5 步：判信号灯，给结论。**

综合前四步定绿 / 黄 / 红灯（标准见核心方法），然后输出一句话结论：问题在哪、现在是什么局面、你现在要做的第一件事是什么。

## 核心方法

### 红绿灯信号判断标准

**绿灯（积极）：**

- 对方主动开话题、主动问你的事
- 回复快、篇幅长、情绪饱满（表情、玩笑、延展）
- 配合你的邀约试探，给具体时间或主动给替代方案
- 连续多轮双向推进，不冷场

**黄灯（中性）：**

- 回你，但不主动；你问一句她答一句，不延展
- 回复短、节奏慢，情绪密度低
- 既不拒绝也不给具体信息，悬在中间
- 原来是绿灯，最近明显变平变淡

**红灯（消极）：**

- 回复越来越慢，或直接不回
- 敷衍："嗯""哦""哈哈"，连续几轮不接话题
- 明确拒绝邀约，或约好的临时取消又不给新时间
- 你一追问，对方退得更快

**判灯原则：**

- 看趋势不看单轮：一两句冷不等于红灯，连续几轮冷才是
- 看行为不看原话：说"最近忙"是原话，忙完也不找你才是信号
- 一次判灯不是永恒：黄灯可以变绿，绿灯放任也会变黄

### 聊天记录分析方法

**四条铁律：**

1. 只看可见原文。记录里写了什么就是什么，没写的不要编。
2. 先确认谁是谁。记录里哪边是自己、哪边是对方先锁死，之后不翻转。
3. 事实和解释分开写。先列可观察事实（主动几次、间隔多久、原话怎么说），再写合理解释，最后标出关键未知（线下发生的事、没说出口的意图）。
4. 证据编号引用。引用记录时指明位置（第几轮、原文），判断错了能回查。

**分析顺序：** 框架 → 需求感 → 话题结构 → 价值传递 → 信号灯。框架是最底层，框架错了，话术改得再漂亮也只是换一身衣服跪着。

## 分阶段策略

**红灯 / 黄灯期：稳框架，不对冲追问。**

- 停止追问："你是不是生气了""我是不是说错什么了"这种话一律不发。追问是最低位框架，只会让灯更红。
- 给空间：黄灯时没话不要硬聊，过两天换个轻松的话题重新开场；红灯时主动停下，等对方或等新机会。
- 自查框架：这段聊天里你在哪句话开始自证、讨好的，标出来。下次同样的坑不踩第二遍。
- 红灯存量战略性放弃：把时间留给增量，别在一段聊死的记录里反复复盘求安慰。

**绿灯期：真诚表达，推进邀约。**

- 好感表达不玩暗的。想表达就明说，高位表达不掉价：有标准、不迎合地表达欣赏。
- 把线上热度落成见面。绿灯期目标只有一个：把聊天推进到一次具体、低压力的见面。线上聊再久不落见面，绿灯也会熄。
- 绿灯也不掉以轻心：保持框架，邀约被拒一次就退回黄灯策略，不连环追。

**切换依据只有信号灯。**

灯是什么颜色，策略就是哪一套。不因为"我感觉她应该有兴趣"提前推进，不因为"再聊聊吧"拖延邀约。信号是唯一的切换依据。

## 常见误区

1. **单句求诊。** 只发一句话问怎么回。脱离上下文的单句没有诊断价值，给出的判断一定是错的。
2. **暗地里试探。** 不明说好感，用"在吗""睡了吗"反复试探。暗戳戳的表达全是低位框架，不会让对方看清你的意图，只会让她看清你的需求感。
3. **客观话题死循环。** 吃了什么 → 爱喝什么 → 工作忙吗，循环往复。没人接情绪的日常琐事聊再多，氛围只会越来越干。
4. **秒回 + 长独白。** 对方轮回你秒回，对方一句话你回一段。投入不对等本身就是信号，你的追回动作只是在放大信号。
5. **用诊断替代执行。** 反复回来分析同一段聊天，分析得越多越不想动。诊断完必须有一个行动，没有行动的诊断是拖延。

## 伦理检查

**本模块越线的做法，一律禁用：**

- **伪装读心：** 装作能看穿对方心思的话术（"我知道你在想什么""你就是口是心非"）。没人有这个能力，装有就是欺骗。
- **贬低打压：** 故意贬低对方来抬高自己、让对方自我怀疑（"你也就这样了""也就我能受得了你"）。这不是策略，是精神控制的雏形。
- **服从测试：** 用突然失联、假想敌、诱导嫉妒来测试对方在意程度。一次清楚的提议换真实信息，不考验人性。
- **虚假稀缺：** 编造"还有很多人等我回""我明天就消失了"制造紧迫感。没有的就是没有，编故事就是欺骗。
- **边界红线：** 不碰对方明确拒绝的话题，不利用对方倾诉时的脆弱推进暧昧，不把对方的私人信息当谈资。对方说停就停，对方的拒绝就是最终答案。

**自查一句：** 如果这句话的技巧不能放在阳光下讲给对方听，就别用。
